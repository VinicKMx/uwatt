# Changelog

All notable changes to uWatt are recorded here.

The project follows semantic versioning after the first public release.

## Unreleased

### Added

- Checkpoint 0 repository foundation.
- Python package skeleton with public `uwatt.Session` facade.
- Typed core domain objects.
- Measurement backend contract.
- Deterministic synthetic instrument backend.
- Strict JSON schemas for configuration, manifest, metrics and diagnostics.
- CLI commands for config validation, synthetic device discovery and board profile listing.
- Initial board profiles for nRF52840 DK, ESP32-C3-DevKitM and NUCLEO-U575ZI-Q.
- Unit and integration tests requiring no hardware.
- CI workflow for formatting, linting, type checking and tests.
- Initial architecture, ADR and project history documentation.
